# Ivy Tools

## Tigrinya Image to Text Converter

Version 1.0

Ivy Tools is a free browser-based OCR tool that
converts printed Tigrinya images into editable text.

## Features

- Tigrinya text recognition
- JPG and PNG support
- Multiple page uploads
- Drag and drop
- Page sorting using up and down buttons
- Remove individual pages
- OCR progress indicator
- Editable extracted text
- Copy text to clipboard
- Download text as a TXT file
- Responsive mobile-friendly design

## Privacy

Files are processed locally in your browser.

The OCR engine and language model are downloaded
from external sources, but the application does
not intentionally upload selected images to a server.

## Technologies

- HTML5
- CSS3
- JavaScript
- Tesseract.js
- WebAssembly
- GitHub Pages

## Run Locally

Start a local development server:

    python3 -m http.server 8000

Open your browser and visit:

    http://localhost:8000

## Limitations

OCR accuracy depends on image quality, font,
lighting, resolution and document layout.

Always review the extracted text for errors.
